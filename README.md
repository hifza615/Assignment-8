🍽️ Salt'n Pepper Website Clone

A responsive front-end clone of the Salt'n Pepper website built using HTML5 and CSS3. This project recreates the design, layout, and visual appearance of the original website while focusing on clean code, modern styling, and responsive web design techniques.

✨ Features
Responsive website layout
Modern and visually appealing design
Navigation bar and multiple sections
Hover effects and smooth styling
Mobile-friendly structure
Built entirely with HTML and CSS


🚀 Technologies Used
HTML5
CSS3

📚 What I Learned
Website layout structuring
CSS Flexbox and positioning
Responsive web design
Styling professional landing pages
Improving UI/UX design skills

This project was created to strengthen my front-end development skills by recreating a real-world restaurant website design using only HTML and CSS.
